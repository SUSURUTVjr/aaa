モールス信号音声認識Webサービス（ブロック処理版）

ファイル構成
- index.html : 画面構造
- style.css  : スマートフォン向け画面
- script.js  : マイク入力、1秒ブロック処理、特徴量抽出、モールス変換
- README.txt : 実行方法と注意事項

実行方法
1. 4ファイルを同じフォルダに置きます。
2. HTTPS対応のWebサーバー、またはlocalhostでindex.htmlを開きます。
3. スマートフォンでマイクの使用を許可し、「録音開始」を押します。
4. 録音中はボタンに「録音中」と表示されます。タップすると停止します。
5. 縦長画面は和文、横長画面は欧文モードです。

ブロック処理
- マイクからのサンプルを約1秒ずつのブロックにまとめます。
- ブロックごとに音量・周期性・周波数候補などの特徴量を抽出します。
- 2ブロック以上がそろうと、古いブロックから符号を判定します。
- 文字途中でブロックが終わった場合は、後続ブロック冒頭も必要な範囲で解析します。
- 処理済みの音声サンプルは保持せず破棄します。音声ファイルの保存・外部送信はしません。

注意
- この版は基本実装です。実際の映像音声やスマートフォンでの精度検証は未完了です。
- 音声特徴量による判定は環境音に影響されます。誤認識を完全に防ぐことはできません。
- 和文モールス表は基本版で、濁音・半濁音・拗音などの完全対応は今後の課題です。
- ScriptProcessorNodeは旧式APIです。必要に応じてAudioWorkletへ移行してください。
- マイク利用には通常HTTPSまたはlocalhostが必要です。
